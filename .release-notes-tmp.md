# v5.12.0-beta.7 — Tile Order + Readiness Shrink

Captain visual review on beta.6 produced two notes; both addressed.

## Changes

- **SLEEP promoted to row 1** — `MEDICAL_VITAL_CLASSES` reordered so `sleep_score` and `sleep_duration` come before `readiness`. New BIOMEDICAL grid:
  - Row 1: HR | TEMP | WEIGHT | SLEEP
  - Row 2: SLEEP TIME | READINESS | EFFICIENCY | BREATHING
  - Row 3: HRV | HRV BAL | BODY BATT | RECOVERY
  - Row 4: RESILIENCE | VO2 MAX | CV AGE | ACTIVITY
  - Row 5: STEPS | ACTIVE | CALORIES | MOBILITY
  - (AUDIO surfaces row 6)
- **READINESS no longer spans 2 columns when empty** — the `tile-composite` (col-span-2) and `tile-value-large` (2rem) classes now apply only when contributing sub-lozenges actually render. Without subs, READINESS collapses to a normal 1-col tile, eliminating the giant empty rectangle in the middle of the grid.
- **Tile slice raised 16 → 20** so the new HAE-derived CALORIES, MOBILITY, AUDIO tiles surface.
- **`.tile-variant-unit` CSS added** (Geordi LCARS review) — body-composition breakdown rows now render the inline unit (e.g. `65.65 KG`) at 0.55rem with 0.75 opacity so it subordinates to the numeric value per LCARS label hierarchy.

## Geordi LCARS review verdict

Approved on color tokens, typography, IA, readiness collapse, and clipping. One blocker (missing `.tile-variant-unit` rule) was caught and fixed before ship.

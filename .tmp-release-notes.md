# v5.8.0 — Sickbay

The "Sickbay" release ships the **Medical Bay dashboard** as a stable feature
and closes every open Medical-tagged issue. Consolidates v5.8.0-beta.1 and
v5.8.0-beta.2 after Geordi + Wesley visual review on live Withings-only and
Oura+Withings dashboards.

## Medical Bay highlights

- **Front anatomical silhouette** with leader-line callouts: head-top body temp Δ,
  forehead body temp Δ, heart HR, sternum BP, wrist SpO₂, weight, hip waist, steps.
- **Readiness composite tile** — large Oura readiness headline (0–100) above a 2×2
  grid of contributor sub-lozenges (RESTING HR · HRV BAL · BODY TEMP · RECOVERY).
  Gracefully collapses to one column for Withings-only profiles.
- **Rest-mode banner** — butterscotch for routine recovery, tomato for illness
  signal. One-shot audio cue on transition (gated through `lcarsAudio.isMuted`).
- **Enum-aware resilience tile** — Oura `resilience_level` (Great / Strong /
  Solid / Low / Exceptional) renders as a colored chip, not a meaningless number.
- **New vitals**: body temp deviation (signed ±°C), HRV balance, sleep efficiency,
  activity score, VO2 max, cardiovascular age, stress resilience.
- **Multi-source variant rendering** — one canonical per kind drives silhouette
  anchor + rollup, additional sources stack beneath in Zone C tiles.
- **FILE ID label + status-pill legend** — clinical header readability,
  full-tier description on the rollup pill with visually-hidden aria text.
- **Privacy posture preserved**: closed shadow root, PHI lint guard, per-profile
  consent gate, default-disabled, admin-gated, screenshot-obfuscator coverage.

## Problem

The Life Support panel clips the nested environment substation's sparkline tray. Previous fix (v4.18.9, `overflow: visible`) was insufficient.

## Root Cause (Geordi's Diagnosis)

`flex: 1` on `.panel-content` in `lcars-panel-frame-styles.js` expands to `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`. The `0%` flex-basis causes height to collapse to zero when content is slotted across nested Shadow DOM boundaries (Life Support → `<lcars-panel-frame>` → `<slot>` → `<lcars-environment-panel>` → its own Shadow DOM → `.env-content` grid).

Secondary factor: `.env-content` uses `grid-template-rows: 1fr auto` — the `1fr` track needs definite available height to resolve, which doesn't exist in the nested context.

## Stories

### Story 1: Fix `.panel-content` flex-basis (primary fix)
**File**: `custom_components/lcars_dashboard/js/src/components/lcars-panel-frame/lcars-panel-frame-styles.js`
**Change**: `.panel-content { flex: 1 }` → `flex: 1 1 auto`
**Impact**: All 12 panels share this base style. Data confirmed zero visual change for standalone panels (parent has no definite height constraint). Only affects nested composition.

### Story 2: Fix `.env-content` grid rows (belt-and-suspenders)
**File**: `custom_components/lcars_dashboard/js/src/panels/environment/lcars-environment-panel-styles.js`
**Change**: `grid-template-rows: 1fr auto` → `auto auto`
**Impact**: Environment panel only. Makes implicit `auto` resolution explicit.

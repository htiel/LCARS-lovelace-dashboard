## Sequenced Implementation Stories

Only IMPLEMENT items appear below.

### Story RC8-1: Shared Formatting and Naming Foundation

Items:
- QA-E10
- QA-E11
- QA-E09

Files to modify:
- `custom_components/lcars_dashboard/js/src/lcars-format-utils.js`
- `custom_components/lcars_dashboard/js/src/lcars-base-panel.js`

Change:
- Extend the shared formatter so data-size and rate-like telemetry values promote to human-readable units instead of exposing oversized raw magnitudes.
- Add timestamp humanization helpers for raw ISO strings and strengthen name-shortening so possessive area prefixes strip cleanly without orphan punctuation.

Implementation order:
- First. Weather and irrigation degraded-state work depend on these helpers.

Test criteria:
- Raw ISO timestamps no longer render verbatim in touched panels or shared row consumers.
- Large storage/data-size values render as scaled units instead of raw MB-sized strings.
- Possessive room prefixes strip cleanly from labels without leaving leading apostrophes, dashes, or extra spaces.

## Risk Register

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| Media compaction hides a player the user still expects to see independently | Medium | Medium | Keep the active player expanded, collapse only clearly unavailable or redundant standby siblings, and preserve direct secondary rows. |
| Last-known weather or irrigation data reads as live instead of stale | Medium | Medium | Label cached/offline context explicitly and keep it visually gray and subordinate to the offline state. |
| Truncation fixes cause wrapping or overflow regressions on narrow screens | Medium | Medium | Limit the rc.8 fix to touched shared primitives and panel styles, then run mobile-width visual validation before closing the pass. |
| New blueprint validation rejects existing loose user payloads | Medium | High | Keep schema minimal, size limits explicit, and error messages actionable so valid payloads continue to pass. |
| Path validation skips previously tolerated odd filenames in `more_pages` | Low | Medium | Fail closed for invalid names and document the naming contract instead of silently traversing unexpected paths. |
| Audit-only items balloon scope during implementation | Medium | High | Treat GEORDI-029 and GEORDI-031 as validation gates, not default code stories. Promote to code only if validation finds a concrete defect. |

## Execution Cadence & Gates (mid-flight)

- **Per-pass gate:** before moving to next pass, `npm run build` must succeed; bundle size delta logged; commit message lists every issue number addressed.
- **Bundle budget:** total growth across all 6 passes ≤ 2% of baseline (current 908 KiB → cap ~927 KiB). If a pass blows the budget, split it before continuing.
- **No mid-flight version bumps.** No mid-flight tags. No mid-flight releases. No mid-flight `gh issue close` (close in batch at final-release time so each issue links to the same shipped tag).
- **Commit cadence:** one commit per pass (or one per logical sub-cluster within a pass). Commit messages: `fix(<surface>): close #N1 #N2 ... [Pass X/6]`.
- **Re-check before editing each file:** grep first — the v5.6 train pattern showed 7+ "open" issues already-fixed in tree.

# 2. Bump 3-file version sync (CRITICAL: all three or HACS won't bust cache)
